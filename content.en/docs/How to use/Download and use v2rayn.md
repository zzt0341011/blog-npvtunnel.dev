## v2rayN Introduction

[v2rayN](https://github.com/2dust/v2rayN) is an open-source VPN software installed on Windows computers. It can change the IP address you use when accessing the internet. For example, if [ChatGPT](https://chatgpt.com/) is not supported in your country, you can use this software to access it. v2rayN is similar to [sing-box](https://sing-box.info/), Clash for Windows, clash.meta, [hiddify](https://hiddify.me/), [v2box](https://v2box.pro/), Shadowrocket, Karing, Surge, and [Stash](https://apps.apple.com/us/app/stash-rule-based-proxy/id1596063349), but it offers many new features. It can hide your identity on the internet and is faster than a traditional **VPN**. If you need a more stable and secure network environment, it is recommended to use paid network nodes. v2rayN supports multiple protocols such as Shadowsocks, VMess, [VLESS](https://vless.app), Reality, Trojan, Hysteria2, and more.
