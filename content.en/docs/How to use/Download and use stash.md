## Introduction to stash

Stash is a VPN software. It has IOS and [MAC versions](https://apps.apple.com/us/app/stash-rule-based-proxy/id1596063349). It can change the IP address you use to access the Internet. For example, if your country does not support [chatgpt](https://chatgpt.com/), you can use this software. Stash is similar to v2rayNG, [sing-box](https://sing-box.info/zh), clash for window, [clash.meta](https://github.com/MetaCubeX/ClashMetaForAndroid), hiddify, [v2box](https://v2box.pro/zh), shadowrocket, karing, surge, etc., but it has many new features. It can hide your identity on the Internet. It is faster than VPN. If you need a more stable and secure network environment, please use a paid network node. Stash supports almost all network proxy protocols, such as shadowrockets, vmess, vless, reality, Trojan, [hysteria2](https://v2.hysteria.network/) and other protocols.
